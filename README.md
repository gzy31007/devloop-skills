# devloop-skills

跨编码 Agent 通用研发闭环技能套件，适用于 Antigravity、Claude Code、Codex 与 OpenCode。

## 安装与更新

```bash
npx skills add gzy31007/devloop-skills -g
npx skills add gzy31007/devloop-skills
```

## 技能清单

| 技能 | 职责 |
| --- | --- |
| `agent-docs` | 面向 Coding Agent 的文档与注释写作规范 |
| `hakimi` | 只读侦察仓库现状并给出下一阶段斜杠命令 |
| `loop-init` | 幂等初始化工作区配置、模板与索引块（自研与客串双模式） |
| `loop-plan` | 前置调研、路线对比与文档边界收敛 |
| `loop-build` | 分支编码、缺陷先红后绿、真实结果自测与交接 |
| `loop-review` | 独立盲审、文档指纹核验、故障注入与附带门禁脚本 |
| `loop-retro` | 两阶段发版门禁、合主干打标签与分层教训沉淀 |
